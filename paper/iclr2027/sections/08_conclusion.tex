\section{Conclusion}

We formulate quantitative-agent harness evolution as intervention on an open,
task-conditioned Research State process. The Evolver connects expected and
observed Worker states to a selected harness component and a falsifiable target
transition, using executable quantitative invariants as observations when
applicable. Rather than equating harness improvement with a single final
answer, the method separates component activation, state correction, official
task outcomes, and repeated or transferred benefit. \Pending{Conclude with the
frozen empirical result after the prospective campaigns are complete.}
